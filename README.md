# WAI Website Dev

Shared development workspace for Workfriend.ai.

This repository is the durable home base for AI-assisted development across Astra, Codex, Claude and other models.

## Main areas

- `website/` - main Workfriend.ai website
- `rehumanizer/` - Rehumanizer app/tool
- `rfp-evaluator/` - RFP evaluation tool
- `experiments/` - prototypes and experimental work
- `docs/` - supporting documentation

## Agent workflow

Before making changes, read:

1. `AGENTS.md`
2. `PRODUCT.md`
3. `CURRENT_STATE.md`
4. `BACKLOG.md`
5. `DECISIONS.md`

Keep this repository as the source of truth for current state, important decisions and future work.
